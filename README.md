# web-copy-share 正文复制网页

局域网内可访问的网页：展示正文文本（逐段复制 / 全部复制）、文件下载/上传回传/在线预览/SHA256 校验、网速测试。零依赖，仅需 Node.js。

## 启动

```
node server.js
```

无需 `npm install`、无需任何第三方包。启动后控制台会打印本机与虚拟机可用的访问地址（默认端口 **24496**）。

## 修改显示内容（核心用法）

**只改 `index.html` 一个文件**：

1. 用任意文本编辑器打开 `index.html`
2. 找到 `<!-- 正文区域：修改这里的内容 -->` 注释
3. 在 `<section class="text-block">…</section>` 里修改文字
4. 新增段落：复制一整个 `<section class="text-block">…</section>` 块；删除段落：删掉整块
5. 保存文件，虚拟机里按 **Ctrl+F5** 强制刷新即生效（无需重启 node）

## 下载区

把文件**放进本文件夹**（支持子文件夹，最深 3 层，页面按顶层目录分组展示），或使用页面上的「上传回传」区直接上传。刷新页面即自动列出（`server.js`、`index.html`、`README.md` 和 `.` 开头的隐藏文件不会列出）。每个文件支持：

- 下载（中文文件名 + 大文件流式 + Range 断点续传，附件形式不会在浏览器打开）
- **SHA256 哈希**：点击「SHA256」计算并自动复制，用于校验下载完整性
- **在线预览**：txt / md / json / log / csv / ini / 图片（png/jpg/gif/webp/svg/bmp/ico）/ pdf 直接内联打开，其余类型返回 415

## 上传回传

页面「上传回传」区支持多选文件或**整个文件夹**（含子目录结构），逐文件流式上传（不设大小上限），带整体进度条，完成后下载区自动刷新。上传路径经严格校验（拒绝 `..` 穿越与服务自身文件）。

## 网速测试

本机延迟（HTTP RTT）、外网延迟（TCP 握手）、上传/下载持续测速（时长可选）+ 速度曲线图 + 流量统计。

## 虚拟机访问

1. 本机运行 `node server.js`，记下控制台打印的局域网地址，例如 `http://192.168.1.100:24496`
2. 虚拟机浏览器（不限系统/浏览器）打开该地址

### 两个前提（打不开时检查）

| 现象 | 解决办法 |
| --- | --- |
| 虚拟机打不开、转圈超时 | ① VM 网络必须是**桥接模式**（NAT 模式访问不到宿主机）② Windows 防火墙首次会拦截，放行 node.exe 或入站 TCP 24496 端口（`netsh advfirewall firewall add rule name="web-copy-share" dir=in action=allow protocol=TCP localport=24496`） |
| 页面能开但复制没反应 | 这是浏览器限制，换用页面上的「复制」按钮（已做兼容处理）；若仍失败请手动全选复制 |

## 常见问题

- **改完内容 VM 里没变化**：浏览器缓存。按 Ctrl+F5 强制刷新（服务端已设 `Cache-Control: no-store`，一般不缓存）
- **本机能开、VM 开不了**：见上表前提检查网络模式与防火墙
- **换端口**：编辑 `server.js` 顶部的 `PORT` 变量
- **端口被占用**：启动时会给出友好提示与查询命令（`netstat -ano | findstr :24496`）
